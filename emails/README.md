# emails/

One file per recipient, `<firstname-lastname>-<company>.md`, written by
`/email`. Top body = the one that gets sent; alternates, follow-up, and
facts-used sit below a `---` line.

Send by copy-paste, or set up the optional terminal sender in
`email-app/` (`/setup email-app`), which is dry-run by default.

Everything here except this README is gitignored.
