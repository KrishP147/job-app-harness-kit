# dms/

One file per person, `<handle>.md`, written by `/dm`. Paste someone's
handle plus what you have on them (bio, posts, what they build, what you
want) and it drafts 2-3 short DMs in your voice, a follow-up line, and
every fact it used about you with its source.

Voice comes from `context/voice.md` (`/setup voice`). Nothing is sent;
copy the draft you like.

Everything here except this README is gitignored.
