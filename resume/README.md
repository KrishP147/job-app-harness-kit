# resume/

Your master resume as `resume.tex` (required). Run `/setup resume` to
add it — paste LaTeX, or give a PDF/DOCX/text and Claude converts it to
LaTeX without changing any facts.

- `resume.tex` — single source of truth. LaTeX only.
- `resume.pdf` — auto-compiled on save (hook) or via `/watch`.

Everything here except this README is gitignored.
